## 用語 quick ref

- **SKPS** … ストローク・キック・プル・スイムの順
- **DPS** … ストローク効率（Distance Per Stroke）
- **Variable** … 強度を変えて泳ぐ
- **Des / Dec** … ディセンディング（本数ごとにタイムを落とす）
- **B-up** … ビルドアップ（後半加速）
- **Negative split** … 後半を速く
- **IM Order** … 4泳法の順（Fr→Ba→Br→Fly）
- **Broken** … セット途中に短い休憩を挟む
- **Contrast** … 強度を交互に切り替える
- **SR** … ストロークレート（1ストロークにかかる秒数）
- **TSS** … タイム＋ストローク数＋心拍数の合計最小化目標
