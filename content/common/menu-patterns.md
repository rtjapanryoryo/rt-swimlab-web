## ドリル変形パターン

- **odd: ヘッドアップ / even: キャッチアップ** … 奇数本でヘッドアップ、偶数本でキャッチアップ
- **odd: Drill / even: Swim** … 奇数本ドリル、偶数本スイム
- **odd: Pull / even: Kick** … 奇数本プル、偶数本キック
- **1本目 H-E / 2本目 E-H / 3本目 E / 4本目 H** … 25m×4本などで本数ごとに強度を変える
- **50m Drill / 50m Form** … 100m単位でドリル→フォームの繰り返し
- **1kick / 2pull** … 25mキック＋50mプル
- **25mSculling / 15mHead up fast / 45mForm / 15mFast** … スカーリング→ヘッドアップ→フォーム→Fast

## 用語 quick ref

- **SKPS** … ストローク・キック・プル・スイムの順
- **DPS** … ストローク効率（Distance Per Stroke）
- **Variable** … 強度を変えて泳ぐ
- **Des** … ディセンディング（本数ごとにタイムを落とす）
- **Ac/CA** … アクセント／キャッチアップ
- **Negative split** … 後半を速く
- **IM Order** … 4泳法の順（Fr→Ba→Br→Fly）
