# メニュー差別化用辞書（カスタム生成で必須参照）

※チープ・汎用表現を避け、種目・期・距離タイプに特化した内容にするための参照一覧。
※**Quickテンプレと同レベルの具体性・プロフェッショナルさ**を目指す。

## 禁止（チープ・差別化なし）
- 「Cho 200m」「Kick 4×50m」「Pull 4×100m」など中身のない汎用表現のみで構成しない
- パターン名（SKPS, DPS, Variable 等）を必ず1つ以上入れる
- 本数で距離を稼ぎすぎない（50m×20本より 200m×4本、400m×2本 を選ぶ）
- W-up を3つ以上に分けて距離稼ぎしない（1〜2セグメントで十分）

## 距離単位の柔軟性
25m・50mに限定せず、100m・200m・400m等を混ぜてよい。例: Kick 4×100m、Pull 3×200m、Main 4×400m。総距離に合わせて本数・距離を調整。
