# 共通コンテンツ（AI・ローカル両方）

このフォルダに置いたファイル（.md / .txt）の内容は、**AIメニュー生成**と**ローカルメニュー生成**の両方で参照されます。

## 読み込ませ方

1. **このフォルダにファイルを置くだけ**で読み込まれます。
2. **対応形式**: `.md`（Markdown）、`.txt`、**.pdf**（テキストを自動抽出）
3. **複数ファイル**: アルファベット順に連結されて1つのテキストとして使われます。
4. **いつ読まれるか**
   - **AIでメニュー生成** … 毎回、サーバーがこのフォルダを読んでプロンプトの「共有参照資料」に差し込みます。
   - **ローカルで生成** … ボタン押下時に API 経由で取得し、generator に渡します。

思想・哲学・プロトコルなどの共有ドキュメントをここに配置してください。
