# 共通コンテンツ（カスタム作成・クイック作成両方）

このフォルダは**事前情報**用です。ここに置いたファイルの内容は**カスタム作成**と**クイック作成**の**両方**で参照され、メニュー生成の質を高めるために使われます。

## 役割

- **思想・規則・メニュー例** などをまとめたファイルを置く場所です。
- 例: `共通メニュー内容＋例20260207.pdf` … 共通のメニュー思想・内容・例を定義したPDF。
- **プロンプトもPDFで載せたい場合** … 下記「プロンプト用ファイル」を使います。

## プロンプト用ファイル（PDFで載せる場合）

- **`prompt.pdf`** または **`prompt.md`** または **`prompt.txt`** をこのフォルダに置くと、**カスタム作成**時にその内容が**システムプロンプトのいちばん上**に挿入されます。
- プロンプト用ファイルは「共有参照資料」とは別扱いで、**先に**読み込まれます。PDFのテキストがそのままプロンプトとして使われます。
- 優先順位: `prompt.pdf` → `prompt.md` → `prompt.txt`（先に見つかった方のみ使用）。入れ替えはファイルの差し替えだけでOKです。

## 読み込ませ方（その他のファイル）

1. **このフォルダに PDF や .md / .txt を置くだけ**で読み込まれます（`prompt.pdf` / `prompt.md` / `prompt.txt` はプロンプト専用のため、共有参照資料には含まれません）。
2. **対応形式**: **`.pdf`**（テキストを自動抽出）、`.md`（Markdown）、`.txt`
3. **複数ファイル**: アルファベット順に連結されて1つのテキストとして使われます。
4. **いつ読まれるか**
   - **カスタム作成** … 毎回、サーバーがこのフォルダを読んでプロンプトの「共有参照資料」に差し込みます。
   - **クイック作成** … ボタン押下時に API 経由で取得し、generator に渡します。

思想・哲学・プロトコル・メニュー例などの共有ドキュメントをここに配置してください。
