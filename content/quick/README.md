# クイック作成用コンテンツ（content/quick）

クイックで作り出すメニューは**すべて**このフォルダ（quick-algorithm）からだけ選ばれます。

## クイックの優先順位と方針

1. **絶対：入れ込んだテンプレ内での出力**  
   クイックの出力は、**menu-templates-9.json などに用意したテンプレから選んだ1件**がそのまま使われます。テンプレに無い内容はクイックでは生成しません。

2. **次に：アルゴリズムのプロンプト**  
   アルゴリズム（quick-algorithm.pdf 等）やプロンプトは、テンプレの「中身をどう作るか」の指針として参照します。出力の主役はあくまでテンプレです。

3. **今後**  
   クイックは要件を増やしていく想定です。上記の優先順位（テンプレ → アルゴリズム）を崩さずに拡張してください。

## PDFについて

**アプリはPDFを読み込めます。** `quick-algorithm.pdf` はサーバー側で開き、テキストを抽出して利用しています。  
メニュー候補の「選び方」は **menu-templates-9.json** で行うため、PDFの内容をこのJSONに**1サンプルを元にn通り**で反映していく形になります。

## 1サンプル → n通りつくる流れ

1. **1サンプル（テンプレート）** … `menu-template-1sample.json` に、メニュー1件分のひな形を置いてあります。全15キーがそろった1オブジェクトです。
2. **n通りつくる** … この1件をコピーし、`menu-templates-9.json` の **S** / **M** / **D** の各配列に貼り付けて並べます。1件ごとに `purpose`・`warmUp`・`drill`・`main` などを書き換えて、9通り（または任意のn通り）にします。
3. **形式** … `menu-templates-9.json` は次の形にします。
   ```json
   {
     "S": [ メニュー1, メニュー2, メニュー3 ],
     "M": [ メニュー1, メニュー2, メニュー3 ],
     "D": [ メニュー1, メニュー2, メニュー3 ]
   }
   ```
4. 各メニューは **menu-template-1sample.json と同じ15キー** を必ず持ってください。  
   `purpose`, `warmUp`, `drill`, `kick`, `pull`, `preMain`, `dive`, `rest`, `main`, `down`, `total`, `intention`, `coachingPoint`, `caution`, `expectedEffect`
5. **今日の狙い・指導ポイント・注意点**はセットで作成します。表示では `purpose`＝今日の狙い、`coachingPoint`＝指導ポイント、`caution`＝注意点として使われます。テンプレ作成時にいずれも空にしないでください。

### クイックメニューのセッティング（セクション順）

- **quick-settings.json** で、メニュー表のセクション表示順を変更できます。テンプレ（menu-templates-9.json）のキー順に合わせて、既定は次の並びです。
- 既定順（テンプレ通り）: `warmUp` → `drill` → `kick` → `pull` → `rest` → `preMain` → `dive` → `main` → `down`
- この順序を変えたいときだけ `sectionOrder` を編集してください。クイック作成・カスタム作成どちらのメニュー表示にも反映されます。

### 貼り付けの注意

- `menu-templates-9.json` はインデント付きで保存してあります。1サンプルをコピーして貼り付けるときは、**配列の要素どうしのあいだにカンマ**を入れ、**最後の要素のうしろにカンマを付けない**ようにしてください。
- エディタで「JSONを検証」するか、保存後にアプリのクイック作成でメニューが選ばれるか確認すると安心です。

## ファイル

| ファイル | 役割 |
|----------|------|
| **quick-algorithm.pdf** | 元ネタ。アプリでテキストは読み込まれる。メニュー候補の「中身」はここを参照して menu-templates-9.json に反映する。 |
| **menu-template-1sample.json** | **1サンプル**。この1件をコピーして n 通りつくるためのテンプレート。 |
| **menu-templates-9.json** | クイック作成で選ばれる候補群。上記1サンプルをコピー・編集して S/M/D に並べたもの。 |
| **quick-settings.json** | クイックメニュー用設定。`sectionOrder` で W-up / Drill / Kick 等の表示順を変更可能。 |

「メニューは quick-algorithm（content/quick）の menu-templates-9.json からだけ選ばれます」と出た場合は、このJSONに有効なテンプレ（purpose や main などが空でないもの）が1件もない状態です。1サンプルをコピーして反映し、テンプレを設定してください。
