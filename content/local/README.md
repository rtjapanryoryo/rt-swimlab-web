# ローカル専用コンテンツ

このフォルダに置いたファイル（.md / .txt / .json）の内容は、**ローカルメニュー生成だけ**で参照されます。AI生成では使いません。

## 読み込ませ方

1. **このフォルダにファイルを置くだけ**で読み込まれます。
2. **対応形式**: `.md` / `.txt` / `.json` / **.pdf**（テキストを自動抽出）
3. **複数ファイル**: アルファベット順に連結されます。
4. **いつ読まれるか** … **ローカルで生成**ボタンを押したとき、API（`/api/content`）経由で取得し、generator に渡します。AIでメニュー生成では読みません。

ローカル専用のルール・テンプレート・補足情報をここに配置してください。
