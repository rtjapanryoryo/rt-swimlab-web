# クイック作成専用コンテンツ

このフォルダに置いたファイル（.md / .txt / .json）の内容は、**クイック作成だけ**で参照されます。カスタム作成では使いません。

## クイック専用アルゴリズム（打ち込み用）

- **`quick-algorithm.md`** または **`quick-algorithm.pdf`** … クイック作成専用のアルゴリズムを書くファイルです。
- .md がある場合はそれを、なければ .pdf を読みます（PDF はテキストを自動抽出）。
- **読み込まれるタイミング**: 「クイック作成」ボタンを押したときだけ、サーバーが `content/local/quick-algorithm.pdf`（または .md）を開き、テキストを抽出してジェネレータに渡します。画面上で「PDFを開く」わけではなく、サーバー側でファイルを読んでいます。

### 上書きのしかた

1. **新しいPDFに差し替えたい場合**  
   このフォルダ内の **`quick-algorithm.pdf`** を、新しいPDFで上書きしてください。
   - 方法A: 新しいPDFを「`quick-algorithm.pdf`」という名前で保存し、`content/local/` の既存の `quick-algorithm.pdf` をそれで置き換える（同じ名前で上書き保存）。
   - 方法B: ターミナルでコピーする例  
     `cp "/Users/andy/Downloads/新しいファイル.pdf" "/Users/andy/rt-swimlab-web/content/local/quick-algorithm.pdf"`
2. 保存・置き換え後、**サーバーを再起動する必要はありません**。次に「クイック作成」を押したときから、新しい内容が使われます。

## 読み込ませ方（その他のファイル）

1. **このフォルダにファイルを置くだけ**で読み込まれます（`quick-algorithm.md` を除く）。
2. **対応形式**: `.md` / `.txt` / `.json` / **.pdf**（テキストを自動抽出）
3. **複数ファイル**: アルファベット順に連結されます。
4. **いつ読まれるか** … **クイック作成**ボタンを押したとき、API（`/api/content`）経由で取得し、generator に渡します。カスタム作成では読みません。

クイック作成専用のルール・テンプレート・補足情報をここに配置してください。
